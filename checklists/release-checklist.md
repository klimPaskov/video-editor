# Release Checklist

- [ ] Supported platforms and dependency versions are documented.
- [ ] Clean installation was tested.
- [ ] Upgrade and rollback were tested.
- [ ] All continuous integration checks pass.
- [ ] Full local media matrix passes.
- [ ] End-to-end fixture passes.
- [ ] A/V synchronization fixture passes.
- [ ] Budget bypass and duplicate submission tests pass.
- [ ] Schema compatibility is declared.
- [ ] Security review is complete.
- [ ] License review covers fonts, sound assets, templates, and provider outputs.
- [ ] Operator acceptance session is complete.
- [ ] Runbook and known limitations are current.
- [ ] Critical and high risks have accepted treatment.
- [ ] Reproduction test succeeds from retained project data.
