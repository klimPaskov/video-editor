# Provider Live Test Checklist

- [ ] Current official provider documentation was reviewed.
- [ ] Test credential is stored outside the repository.
- [ ] Project data classification allows provider use.
- [ ] Network access is explicitly enabled.
- [ ] A hard test budget is approved and unexpired.
- [ ] Request estimate plus reserve fits the budget.
- [ ] Request hash matches the spend approval.
- [ ] Local job is persisted before submission.
- [ ] Idempotency or duplicate prevention is active.
- [ ] Polling can resume from persisted state.
- [ ] Download enters quarantine.
- [ ] Output media fully decodes and matches requested properties.
- [ ] Actual cost is recorded when available.
- [ ] Provider request and response are stored with secrets redacted.
- [ ] Test asset is reviewed for relevance and factual safety.
