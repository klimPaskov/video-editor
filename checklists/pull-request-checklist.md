# Pull Request Checklist

- [ ] Scope matches one coherent task group.
- [ ] Public behavior and contracts are documented.
- [ ] New dependencies have a reason.
- [ ] No source media, credentials, or provider outputs are committed.
- [ ] Source immutability is preserved.
- [ ] Timeline calculations have unit or property tests.
- [ ] Process arguments are arrays and shell execution is absent.
- [ ] Paths are resolved and bounded.
- [ ] Approval staleness is tested where relevant.
- [ ] Paid submission cannot bypass budget checks.
- [ ] Retry cannot duplicate remote work.
- [ ] Persisted examples validate.
- [ ] Full required checks pass.
- [ ] Documentation and ADRs are updated.
- [ ] Known risks are recorded.
