# Focus and Pacing QA Checklist

## Purposeful zooms

- [ ] Every zoom has one allowed purpose.
- [ ] The actual target is visible before the zoom starts.
- [ ] The target remains relevant until the zoom ends.
- [ ] The visible target is centered with useful context.
- [ ] Motion uses smooth ease in and ease out.
- [ ] No shake, jitter, snap, drift, overshoot, or empty edges are visible.
- [ ] No unrelated window, tab, cursor action, or content is included.
- [ ] Captions and approved overlays remain readable.
- [ ] Low-confidence candidates use no zoom or appear in one batched review.

## Prompt speed-ups

- [ ] An explicit operator request exists.
- [ ] The range contains only visible prompt writing or prompt dictation.
- [ ] The first and last action frames match the declared boundaries.
- [ ] Browsing, reading, waiting, navigation, and result inspection are excluded.
- [ ] Production sound remains audible unless an exception was explicitly requested.
- [ ] Pitch and synchronization are acceptable.
- [ ] Expected and actual retimed durations agree.
- [ ] Re-transcription confirms speech remains present.
- [ ] Low-confidence boundaries use normal speed or appear in one batched review.
