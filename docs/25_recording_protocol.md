# Recording Protocol

## Preferred setup

- evenly lit green screen with subject separation
- fixed shutter and white balance
- clean microphone track
- clap or other sync reference when camera and audio are separate
- one numbered file per logical segment when possible
- screen and camera recorded as separate feeds for picture-in-picture work

## Performance conventions

Pause after mistakes, restart the full sentence, and leave a clean beat between takes. Hold replacement objects clearly for the prompt frame. Avoid green clothing, reflective green spill, and excessive motion blur.

## Before editing

Back up source footage, verify file counts and sizes, and record the intended segment order. The workflow can analyze messy footage, but consistent recording structure reduces ambiguous cuts and tracking failures.
