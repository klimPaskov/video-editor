# Recording Protocol

## Preferred setup

- stable screen resolution and frame rate
- close unnecessary windows and notifications before recording
- record system audio and microphone on separate tracks when possible
- one numbered file per logical segment when possible
- keep prompt-writing actions visible and unobstructed

## Performance conventions

Pause after mistakes, restart the full sentence, and leave a clean beat between takes. Keep the cursor visible while writing prompts and avoid unnecessary cursor wandering.

## Before editing

Back up source footage, verify file counts and sizes, and record the intended segment order. Consistent recording structure reduces ambiguous cuts and makes purposeful zooms easier to review.
