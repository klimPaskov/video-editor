# Roadmap

## Milestone 0: verified local foundation

Python, Node, FFmpeg, schemas, tests, process adapters, and dependency checks
pass.

## Milestone 1: immutable ingest

A source is hashed, probed, and preserved in a resumable project revision.

## Milestone 2: evidence and plan

Local transcript, silence evidence, edit proposals, focus plan, effect plan, and
Gate 1 review work.

## Milestone 3: base edit

Approved keep ranges and prompt-action speed-ups render with synchronized
picture, audible pitch-preserved sound, time mapping, and QA.

## Milestone 4: Remotion composition

Typed visual timelines render text, captions, graphics, B-roll,
picture-in-picture, and purposeful UI focus.

## Milestone 5: reviewed screen-recording delivery

Segment previews, re-transcription, QA, Gate 2, final QA, Gate 3, MP4 delivery,
backup verification, and safe cleanup work across immutable revisions.

## Future work

Future adapters and integrations must be isolated from the local core and may
not change the supported screen-recording path without a new accepted decision,
tests, and documentation.
